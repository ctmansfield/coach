Manual factual event

Record what happened, when you know it happened, and what remains unknown. This page works offline and does not contact Mother or send notifications.

Offline draft only. Export creates a local file for later verified import into Mother. It is not saved to the physiology archive, authenticated, or interpreted as a clinical outcome.

1 · What are you recording?

Use the existing archive identifier, not a new identifying name. Not stored by this page.
Use specific facts. The text is preserved as a reported statement, not a measurement or medical interpretation.

2 · Timing and context

The recorded-at time is captured automatically when you export. Leave an optional time blank if unknown. Times entered here require an explicit UTC offset.

3 · Link to a previously recorded event

This link must resolve to an existing Mother event during import. Acknowledgment never proves that an action occurred.

Export

This browser creates a SHA-256-checked Coach event envelope and starts a local download. The downloaded file can contain sensitive information. Keep it private; do not put it in a public repository.

No background syncing, analytics, readiness scoring, browser storage, or intervention control is enabled. The event is not an archived record until Mother separately validates and accepts it.
